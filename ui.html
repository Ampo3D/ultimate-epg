🗑 Removed automatically

Sources that stayed dead (or out of date) too long are taken out of use by themselves. Every 3 days they get re-checked and come back on their own if they work again. Press Restore to bring one back now and never remove it automatically.

Your sources

Add as many playlists (M3U) and guides (XMLTV, .xml or .xml.gz) as you like. A URL or a file path on this PC both work. Higher sources win when two guides cover the same channel — use ▲▼ to set priority.

🔎 Auto-found guides

Every time the sources update, Ultimate EPG searches the internet (guide websites and GitHub) for guides covering any channel that still has no guide, tests them, and adds the ones that work. Guides that stop working are removed automatically.
